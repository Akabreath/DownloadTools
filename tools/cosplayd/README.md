# cosplayD 📸

Cosplay 页面图片下载工具 — 输入页面链接，自动提取正文 p 标签下的所有图片，
支持在线预览、灯箱放大、并发下载、ZIP 打包、历史记录。

## 一、这是什么

cosplayD 是 DownloadTools 门户中的第一个下载工具，挂载在 `/cosplayd/` 路径下。
它专门针对 cosblay 等 WordPress 建站的 Cosplay 图集站点：只要粘贴一个图集页面
链接，就能自动提取正文中的所有原图，在线预览后一键下载。

设计目标：**让"打开页面 → 数图片 → 逐张另存为"这件繁琐的事变成"粘贴链接 → 点下载"。**

## 二、功能特性

- 🔗 输入页面链接，自动解析页面标题 + 正文 p 标签下的所有图片
- 🖼 图片预览网格 + 灯箱放大（键盘 ← → 切换，Esc 关闭）
- 📦 / 🖼 两种下载格式：ZIP 打包 / 图片文件
- 🌐 / 🖥 两种保存方式：浏览器直接下载（默认）/ 保存到服务器
- 📊 实时进度：百分比、已下载数、耗时、失败列表
- 🕘 历史任务记录（重启后保留），可一键清除
- 🛡 图片代理转发，绕过防盗链，解决跨域预览
- 🏠 返回主页按钮，随时回到 DownloadTools 门户

## 三、工作原理（详细）

### 1. 页面解析（parse_page）

输入任意链接后，后端抓取页面 HTML，用 BeautifulSoup 解析：

```
抓取 HTML → 定位正文容器 → 遍历 p 标签 → 提取 img → 清洗 URL
```

- **定位正文容器**：优先找 `div.entry-content`（WordPress 图集标准容器），
  找不到则回退到 `article` 或 `#content`，最后兜底整个页面。
  这样能避开页头导航、侧边栏推荐位、页脚里的无关图片。
- **只取 p 标签下的 img**：按需求只提取正文段落里的图片，排除布局元素。
- **src 优先原图**：每个 img 优先用 `src` 属性（通常是原图），
  仅当 src 缺失或为 1x1 占位图时，才从 `srcset` 中按宽度值挑最大的一张。
  这保证下载到的是高清原图而不是缩略图。
- **URL 清洗**：跳过 base64 内嵌图和 blank 占位图；
  `//` 开头补 `https:`，`/` 开头拼上站点域名。
- **去重保序**：保持图片在页面的原始顺序，去掉重复 URL。

### 2. 图片代理（/api/img）

Cosplay 站点常带防盗链（Referer 校验），且浏览器直接加载跨域图片可能被拦。
后端提供 `/api/img?url=xxx` 代理端点：后端带上浏览器 UA 和 Referer 抓图，
再转发给前端。这样：

- 预览缩略图能稳定显示（后端视角不受跨域限制）
- 下载时后端也带 Referer，绕过防盗链 403

### 3. 并发下载（download_one + run_download）

- 创建下载任务后，后端用 **aiohttp 异步并发**（默认 8 并发）批量拉取图片。
- 每张图下载前校验：HTTP 200 + 内容大于 100 字节（过滤错误页/空图）。
- 文件名取 URL 末尾（如 `99935090133381.jpg`），重名自动加序号。
- 全程进度写进任务对象：`done / total`、百分比、累计字节数，
  前端每秒轮询 `/api/tasks/{id}` 刷新进度条。

### 4. ZIP 打包

若选择"ZIP 打包"，下载完成后在下载目录同级生成
`<页面标题>.zip`（ZIP_STORED 模式，图片本身已压缩，直接存储更快）。
前端完成后显示"📦 下载 ZIP"按钮，点击即从浏览器下载。

### 5. 历史记录

任务完成后把标题、成功/失败数、大小、耗时、时间戳写入 `history.json`
（保留最近 50 条，重启不丢）。前端历史区展示，支持"🗑 清除历史"。

## 四、使用步骤

1. **打开工具**：访问 `http://localhost:8800/` → 点击 cosplayD 卡片
   （或直接访问 `http://localhost:8800/cosplayd/`）
2. **粘贴链接**：把 cosblay 等站点图集页链接粘贴到输入框，点「🔍 解析页面」
3. **预览确认**：网格展示所有图片缩略图，点击可放大灯箱预览；
   右上角可切换"显示缩略图"
4. **选择下载方式**：
   - 格式：ZIP 打包（推荐，一个文件搞定）或图片文件（逐张）
   - 保存到：浏览器（默认，下载到本地）或服务器（存到 downloads/ 目录）
5. **开始下载**：点「⬇ 开始下载」，进度条实时显示百分比和计数
6. **完成**：浏览器模式自动触发下载；ZIP 模式可点按钮重新下载；
   历史区保留记录，可随时取用 ZIP

## 五、目录结构

```
tools/cosplayd/
├── backend/
│   └── main.py          # FastAPI 后端（解析/下载/打包/代理/历史）
├── frontend/
│   ├── index.html       # 前端页面
│   ├── css/style.css    # 样式（深色玻璃拟态主题）
│   └── js/app.js        # 前端逻辑（BASE 前缀自动推断挂载路径）
├── downloads/           # 下载保存目录（按页面标题命名文件夹）
└── history.json         # 历史记录（自动生成）
```

## 六、技术要点

- **FastAPI + aiohttp**：全异步 IO，高并发下载不阻塞
- **BeautifulSoup**：HTML 解析，正则辅助提取
- **BASE 前缀机制**：前端所有 API 请求用相对路径 + `BASE` 变量自动推断
  （挂载在 `/cosplayd/` 时 BASE=`/cosplayd`，独立运行时为空），
  因此同一套前端既能作为门户子应用，也能独立部署
- **任务状态机**：queued → downloading → packing → done，
  前端每秒轮询，浏览器下载模式在 done 后自动触发

## 七、常见问题

- **解析不到图片**：确认链接是图集正文页而非首页/分类页；站点可能结构特殊，
  可以发我链接排查
- **部分图片失败**：看进度面板的失败列表，通常是单张超时或防盗链升级，
  重试一次即可
- **想保存到服务器**：切换"保存到"为服务器，文件在
  `tools/cosplayd/downloads/<标题>/` 下
